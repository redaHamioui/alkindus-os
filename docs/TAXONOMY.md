# TAXONOMY (T1–T10)

This short taxonomy is designed to be pragmatic and cover the most common operational task types for initial blueprints.

T1 — System administration
T2 — User support / case handling
T3 — Deployment and release management
T4 — Security configuration & policy
T5 — Monitoring & observability
T6 — Backup & retention
T7 — Research, prototyping & model tuning
T8 — Access management / approvals (often human-required)
T9 — Compliance, audit & reporting
T10 — Network operations & connectivity

Mapping guidance
- Map each typical task to one primitive.
- If a task spans primitives, choose the most operationally significant primitive.
- Mark `human_required: true` for tasks that legally or operationally require a human decision.
